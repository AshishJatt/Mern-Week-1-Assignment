# Full Stack Web Development (MERN) - Week 1 Assignment

This repository contains the complete solution for Week 1 assignment covering Frontend Fundamentals (HTML, CSS, React Basics).

## Included Tasks

1. **Personal Portfolio Website** (`/portfolio`)
   - Semantic HTML5 structure with About, Education, Projects, and Contact sections.
   - CSS3 styling using Flexbox and Grid for responsive design.

2. **React Components Practice** (`/react-app/src/Components.jsx`)
   - 5 reusable React components: `Header`, `Footer`, `Card`, `Button`, and `Form`.
   - Dynamic rendering with props and state management.

3. **Mini Project: React Blog UI** (`/react-app`)
   - Displays post cards loaded from JSON (`posts.json`).
   - Integrated search bar and category filtering.
